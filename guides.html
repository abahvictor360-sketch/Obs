Part 1

Getting started

New to OBSpad? Read these in order: by the end you will have your scenes ready and be live.

Install OBSpadAndroid tablet or iPad

  1. Android: open obspad.vercel.app on the tablet and tap Android tablet. Open obspad.apk, allow your browser or Files app to install unknown apps, then tap Install.
  2. iPad: on a Mac or Windows PC install Sideloadly or AltStore, download obspad-unsigned.ipa, connect the iPad by cable and install it with your Apple ID. On the iPad, trust your Apple ID in Settings › General › VPN & Device Management and turn on Developer Mode if asked. With a free Apple ID, re-sign it every 7 days.
  3. Open OBSpad and allow the camera and microphone. It opens with a starter scene so you can try things straight away.
  4. New builds: Help › Check for Updates… tells you when one is ready.

The OBSpad screenWhat each part does

  1. Menu bar: File, Edit (undo, transform), View (Studio Mode, Multiview, projectors), Docks, Scene Collection, Tools and Help.
  2. Program: the picture your viewers see. Long-press it for projector and cast options.
  3. Source toolbar: Properties, Filters and quick settings for the selected source.
  4. Scenes: your shots, such as Welcome, Worship, Sermon. Tap one to switch.
  5. Sources: what is in the scene: cameras, pictures, text, videos. The eye shows or hides one, the lock stops it moving.
  6. Audio Mixer: a fader, meter and mute button for every mic and sound.
  7. Scene Transitions: how one scene changes to the next (Fade, Cut, Slide…) and how long it takes.
  8. Controls: Start Streaming, Start Recording, Replay Buffer, Studio Mode, Plugins and Settings.

Docks can be closed, resized and brought back from the Docks menu.

Portrait and smaller screensTabs instead of docks

  1. Hold the tablet upright: Scenes, Sources, Mixer and Transitions become tabs under the picture.
  2. Start Streaming, Start Recording and Studio Mode stay in the bar above the tabs.
  3. Everything else works the same as in landscape.

Make your scenesOne scene per shot

  1. In the Scenes dock tap +, type a name (for example Sermon) and tap OK.
  2. Make one scene for each part of your service or show: Welcome, Worship, Sermon, Offering, Be Right Back.
  3. Tap a scene to put it on Program. Use the ⋮ button to rename, duplicate or remove it, and the arrows to change the order.
  4. Keys 1–9 on a keyboard switch to scenes 1–9.

Add sourcesCameras, pictures, text, videos and more

  1. Pick a scene, then tap + in the Sources dock.
  2. Choose the kind of source: Video Capture Device (tablet camera), Image, Text, Media Source (video), Phone / Encoder, Browser and more. Which one do I need?
  3. Give it a name, set it up in Properties (with a live preview) and tap Add.
  4. To use the same source in another scene, add it again and pick Add existing.

Move, resize and cropDrag, pinch and Transform

  1. Tap a source on the canvas: red handles appear. Drag to move it, drag a corner to resize, pinch to scale and twist to rotate.
  2. For exact numbers open Properties › Transform: position, size, rotation, how it fits its box, and Crop for each side.
  3. Quick buttons: Fit to Screen, Stretch to Screen, Center, Flip. Edit › Undo takes back a mistake.
  4. Lock a source (padlock in the Sources dock) so it can’t be moved by accident.

Titles and lower thirdsText source

  1. Add a Text source and type the words, for example a speaker’s name.
  2. Set the font size, bold or italic, text colour, outline and background colour.
  3. Drag it to the bottom of the canvas for a lower third. Add a Scroll filter for a news ticker.

Studio Mode: get the next shot readyPreview, then Transition

  1. Tap Studio Mode in Controls. The screen splits into Preview (left) and Program (right, live).
  2. Tap a scene: it opens in Preview, where you can change it without viewers seeing.
  3. Tap Transition to send Preview to Program, use a quick transition (Cut, Fade, Fade to Black), or drag the T-bar by hand.
  4. Tap Studio Mode again to go back to one picture.

TransitionsFade, Cut, Slide, Swipe, Fade to Black

  1. In Scene Transitions choose the transition used when you switch scenes, and its Duration.
  2. 300–500 ms feels smooth; use Cut for instant changes.
  3. In Studio Mode, + next to Quick Transitions adds your own buttons.

Audio Mixer basicsLevels and mute

  1. Every mic and sound has a fader, a meter and a speaker button to mute it.
  2. Speak normally: the meter should reach the yellow and never the red. Pull the fader down if it hits red.
  3. The buttons next to the fader set the input, mic adjustments and audio sync offset; ⋮ opens the filters.

Connect to Facebook or YouTubeSettings › Stream

  1. Tap Settings in Controls and open Stream.
  2. Pick your Service: Facebook Live, YouTube, Twitch, Kick, Telegram, Instagram Live, or Custom for any RTMP server.
  3. Paste your Stream key (Paste stream key does it in one tap). For Facebook, YouTube, Twitch and Kick the server is filled in for you. Telegram, Instagram and WhatsApp

Start streaming and recordingControls dock

  1. Tap Start Streaming. The button turns red and the timer at the bottom right counts up. On Facebook click Go live once the preview appears there.
  2. Start Recording saves a video on the tablet at the same time (or on its own). Recordings go to the gallery / Photos.
  3. Tap again to stop. If the internet drops, OBSpad reconnects by itself.
  4. Keep the tablet plugged in and the screen on: Settings › General › Keep screen on.

Bitrate, recording and replaySettings › Output

  1. Video bitrate: 2500–4000 kbps for 720p, 4500–6000 for 1080p. Lower it if the stream stutters.
  2. Stream delay, Replay buffer length, audio bitrate and stereo.
  3. Recording format: MP4 plays everywhere; FLV survives a crash or flat battery.

Picture size and frame rateSettings › Video

  1. Output resolution: 1280x720 is the safest; 1920x1080 needs a recent tablet; 2560x1440 for YouTube only.
  2. Frame rate: 30 FPS for most streams, 60 for sport or games on a fast tablet.

Get help and send feedbackHelp menu

  1. Help › Guides opens this page.
  2. Help › Send Feedback… reports a problem or suggests a feature, with your build filled in.
  3. Help › Keyboard Shortcuts lists every shortcut.
Part 2

Go live on social media

OBSpad streams to any service that gives you a server and a stream key.

Facebook and YouTubeOnly the stream key

  1. Facebook: Live Producer › Streaming software › copy the Stream key. YouTube: YouTube Studio › Go live › Stream › copy the Stream key.
  2. In OBSpad: Settings › Stream, choose Facebook Live or YouTube (RTMPS) and paste the key.
  3. Tap Start Streaming. On Facebook, click Go live once the preview appears.

Telegram channels and groupsLive stream with other apps

  1. In Telegram open your channel or group (you must be an admin) and start a Live stream (in groups: Video chat). Choose Stream with… to see the Server URL and Stream key.
  2. In OBSpad: Settings › Stream › Service: Telegram. Paste the Server URL (like rtmps://dc4-1.rtmp.t.me/s/) and the Stream key.
  3. Tap Start Streaming in OBSpad, then Start streaming in Telegram.
  4. Keep the key private; Revoke in Telegram gives you a new one.

Instagram LiveLive Producer on instagram.com

  1. On a computer go to instagram.com (on a tablet: the browser in desktop mode) › Create › Live video. Copy the Stream URL and Stream key.
  2. In OBSpad: Settings › Stream › Service: Instagram Live. Paste both.
  3. Tap Start Streaming in OBSpad. When the preview appears on instagram.com, click Go live.
  4. The key is new for every live: paste the new one each time.

Instagram is vertical; OBSpad sends 16:9, which shows with bars or cropped on phones. Keep faces and text in the middle. Instagram may ask for a professional (creator or business) account.

WhatsAppNo live streaming yet: two ways around it

WhatsApp has no live streaming and no stream key, so no app can stream into it directly. These work today:

  1. Share a live link: go live on YouTube, Facebook or Telegram and post the link in your WhatsApp groups, Channel or Status.
  2. Put OBSpad into a WhatsApp video call (up to 32 people): share your screen from the tablet with the Call Feed, or use a laptop with an HDMI capture card. How

Several platforms at onceRestream services

  1. OBSpad sends one stream at a time.
  2. To reach several platforms, stream to a restream service (Restream, OneStream, Castr): choose Custom and paste its server and key.
  3. Add your Facebook, YouTube, Telegram and Instagram destinations in that service.
Part 3

Video calls: Zoom, Google Meet, WhatsApp and Telegram

Send your Program into a call, so everyone sees your scenes, slides and lower thirds. Open Tools › Send to a Video Call… (or long-press Program › Video call…).

From this tablet: share your screenNo extra equipment

  1. Open Tools › Send to a Video Call… and pick your app: the steps change for each one.
  2. Join the call in the call app and start screen sharing:
    • Zoom: Share › Screen › Start now (iPad: Start Broadcast). On Android, turn on Share audio to send video and music sound too.
    • Google Meet: ⋮ More › Share screen › Start sharing.
    • WhatsApp: in a video call tap the share-screen button (a phone with an arrow) › Start now.
    • Telegram: in a video call or group video chat, ⋮ › Share Screen › Start now.
  3. On Android 14 and newer choose A single app › OBSpad, so only OBSpad is shared (no notifications).
  4. Come back to OBSpad and tap Open Call Feed. The call keeps running in the background.
  5. Turn your camera off in the call so OBSpad can use the tablet camera: only one app can use it at a time.

Callers hear the call’s own microphone. Videos and music in OBSpad only reach them if the call app offers “Share audio”. For OBSpad’s full sound mix, use a laptop with a capture card (below) or a Telegram live stream.

The Call FeedOnly your Program on screen

  1. Open Call Feed fills the screen with your Program: no buttons, menus or docks, so callers see a clean picture.
  2. Tap the screen to show the scene buttons and Back to OBSpad. They hide by themselves after 4 seconds.
  3. Tap a scene to switch to it (in Studio Mode it is sent to Program). With a keyboard, keys 1–9 switch scenes without showing anything.
  4. The screen stays on while the Call Feed is open.

Telegram groups and channels: live streamBest quality, with OBSpad’s sound

  1. For a Telegram group or channel, a live stream beats screen sharing: full quality and OBSpad’s whole sound mix.
  2. In the group or channel start a Live stream (groups: Video chat) and choose Stream with….
  3. In OBSpad, Set up Telegram streaming opens Settings › Stream with Telegram chosen: paste the Server URL and Stream key and tap Start Streaming. More

On a laptop: OBSpad as the webcamZoom, Meet, WhatsApp, Telegram and Teams desktop apps

  1. HDMI (best): connect the tablet’s HDMI out (USB-C to HDMI) to a USB HDMI capture card plugged into the laptop. In the call app’s settings choose the capture card as the camera and the microphone: callers get your Program and OBSpad’s sound.
  2. Wi-Fi: turn on Teleport Output in Tools › Plugins, add a Teleport source in OBS on the laptop and start OBS’s Virtual Camera: the call app can then pick OBS Virtual Camera. Teleport setup. NDI Output with NDI Tools’ Virtual Input works too.
  3. The tablet stays free to run the show while the laptop handles the call.
Part 4

Screens, projectors and Multiview

Show the program on a TV or monitorCable, USB-C or docking station

  1. Plug the monitor into the tablet with a USB-C to HDMI adapter, or into your docking station.
  2. OBSpad shows the Program on it full screen. To choose, long-press Program, or use View › Fullscreen Projector or View › Multiview.
  3. Nothing shows up? Open Tools › Docking Station & Screen: it lists what the tablet detects and why a screen may be missing.

Use the MultiviewPreview, Program and up to 16 scenes

  1. Open View › Multiview (Fullscreen) and pick This tablet, or a connected screen or TV.
  2. On the tablet, tap a scene to put it in Preview, or double-tap it (or hold it for a second) to send it straight to Program with your transition.
  3. Choose 4, 6, 8 or 16 scenes with the layout button at the top. Close it with the × button or the back gesture. Program shows a red border, Preview a green one.

Multiview touch controlsTap, double-tap and hold

Tap a scene
Puts it in Preview (green border). With Studio Mode off, it goes live straight away.
Double-tap a scene
Sends it to Program (red border) with your transition. The scene that was live moves to Preview.
Hold a scene for 1 second
The same as a double-tap: the scene goes live. A shorter hold does nothing.
Layout button (top right)
Shows 4, 6, 8 or 16 scenes below Preview and Program.
Back to OBSpad, ×, back gesture or Esc
Closes the Multiview and returns to the studio.

Cast to a smart TVSmart View, Miracast or AirPlay

  1. Long-press Program and tap Cast to a wireless screen….
  2. Android: pick your TV in the Cast or Smart View screen that opens. iPad: open Control Center, tap Screen Mirroring and pick your Apple TV.
  3. When it connects, the TV shows the Program while you keep working on the tablet. Chromecast mirrors the whole tablet instead.

Every source is added the same way: in the Sources dock tap +, pick the type, give it a name, set it up in its Properties (you see a live preview there) and tap Add. Long-press it in the Sources dock or use the bar under the canvas for Properties and Filters later.

Tablet cameras

Any tabletFront or back camera
  1. Sources + › Video Capture Device.
  2. Pick Front or Back, and a Resolution: 720p is recommended; 1080p and 4K need a recent tablet.
  3. Use the camera controls for zoom, torch, exposure and focus lock (stops the camera hunting for focus when people move).
  4. Turn on Mirror front camera if you want the selfie view.

Most tablets can run only one camera at a time. Using the front and back camera in visible scenes together, or a built-in camera with a USB camera, may show an error on one of them. Cameras pause while you’re in another app.

HDMI cameras and capture cards

HDMI capture card (UVC) or USB webcamUSB-C hub or OTG adapteriPad: iPadOS 17 or newer
  1. Connect the camera’s HDMI out to a UVC capture card (most cheap “HDMI to USB” sticks are UVC), and the card to the tablet with a USB-C adapter or hub.
  2. Sources + › USB Video Capture. Android asks for permission the first time: allow it.
  3. Pick the device if more than one is plugged in. The picture appears in the preview.
  4. Sound from the card shows up as a USB sound card: add an Audio Input Capture and choose it, or leave it on Automatic.

Turn off the camera’s on-screen display (HDMI info) in its menu. Use the camera’s “clean HDMI” output at 1080p30 or 720p30. Power the hub: capture cards need more current than the tablet’s port gives.

One USB video device works at a time. If nothing appears: unplug and replug the card, check the tablet supports USB OTG, and try another cable or hub.

Screen Capture: other apps and games

Android 10+ or iPad
  1. Sources + › Screen Capture, then tap Start screen capture.
  2. Android: allow the screen-recording prompt. iPad: choose OBSpad Screen in the broadcast sheet and tap Start Broadcast.
  3. Switch to the app or game. Your other sources stay on top of it and the stream keeps running.
  4. For the app’s sound on Android, add Audio Output Capture.

While OBSpad is open, the screen source shows a status card instead of a mirror of OBSpad itself. Phone-call audio from Zoom, Teams or Meet can’t be captured on Android (the system blocks it): see meetings.

A phone camera with sound (RTMP)

A phone with Larix Broadcaster (free)Same Wi-Fi or network
  1. In OBSpad: Sources + › Phone / Encoder (RTMP / SRT). Keep RTMP selected. The properties show the Server (this tablet’s address), a Stream key and a QR code.
  2. On the phone, install Larix Broadcaster (Android or iPhone).
  3. Scan the QR code with the phone’s normal camera: Larix opens and adds the connection. Or in Larix: Settings › Connections › New, and paste the Full address.
  4. In Larix’s video settings choose H.264 (not HEVC), 1080p or 720p, 30 fps, 4–6 Mbps; audio AAC.
  5. Tap the record button in Larix. Within a second or two OBSpad shows “Receiving”, the picture, and the phone’s sound in the Audio Mixer.

Other apps and encoders

  • Prism Live, Streamlabs mobile, CameraFi Live: Custom RTMP with the Server and Stream key.
  • OBS on a laptop: Settings › Stream › Custom, Server and Stream key from OBSpad.
  • GoPro, DJI, ATEM Mini, vMix, hardware encoders: RTMP URL = Full address (or Server + key).
  • Another OBSpad: Settings › Stream › Custom RTMP with this tablet’s address and key.

Several phones: add one Phone / Encoder source per phone; each needs its own Stream key. If the sound arrives before the picture, use the mixer’s Audio sync offset (timer button).

SRT: phones over weak Wi-Fi or the internet

Larix, OBS, vMix, a hardware encoder or ffmpeg that sends SRT

SRT sends lost pieces again, so the picture stays clean on busy Wi-Fi, mobile data or across the internet. Use it instead of RTMP when RTMP stutters.

  1. Add a Phone / Encoder source and choose SRT in its properties. You get an SRT address like srt://192.168.1.20:9000?streamid=phone123, the host and port, and the Stream ID.
  2. Larix: scan the QR code, or New connection with the SRT address; mode Caller.
  3. OBS: Settings › Stream › Custom, Server = the SRT address, Stream key empty.
  4. vMix, Haivision, Teradek, Magewell and other encoders: SRT caller mode, the tablet’s IP and port 9000, Stream ID = the key, latency 120–500 ms.
  5. Leave the passphrase / encryption off; encrypted callers are refused. Use H.264 video and AAC audio.

Over the internet the phone must reach the tablet: forward UDP port 9000 on the router to the tablet, or use a VPN like Tailscale or ZeroTier on both devices and use the tablet’s VPN address.

Old phones as webcams and IP cameras

DroidCam or IP Webcam on the phone, or an IP camera
  1. Sources + › Network Video (phone / IP camera), then choose the Source:
    • DroidCam (Android/iPhone): open the app, enter the WiFi IP it shows. Switch front/back in the DroidCam app.
    • IP Webcam (Android): tap Start server, enter its IP. Pick Back or Front camera right in OBSpad.
    • MJPEG URL: IP cameras and ESP32-CAMs, e.g. http://user:password@camera.local/mjpg/video.mjpg.
    • Stream URL: HLS (.m3u8) or an HTTP video stream.

These carry video only and are lighter on quality. For a phone camera with sound, use Phone / Encoder instead.

NDI® sources

NDI runtime in the buildSame network (wired or good Wi-Fi)
  1. Sources + › NDI® Source. OBSpad searches the network and lists the senders, e.g. STUDIO-PC (vMix - Output 1).
  2. Pick one. Video and sound arrive together; the sound gets a fader in the Audio Mixer.
  3. On busy Wi-Fi turn on Low bandwidth (NDI’s preview stream).

Senders: vMix, OBS with DistroAV, NDI PTZ cameras, the NDI HX Camera app on a phone, Microsoft Teams with NDI turned on, Zoom Rooms, or another OBSpad with NDI output.

NDI needs the NDI® runtime, which is included only when the build is made with the NDI licence accepted (see ndi.video). Otherwise the source explains it isn’t available.

Teleport from OBS or another OBSpadPicture and sound over Wi-Fi

  1. On the sender: in OBS with the Teleport plugin, turn on Tools › Teleport (or add a Teleport filter to a scene). In another OBSpad, turn on Teleport Output in Tools › Plugins.
  2. In this OBSpad: Sources + › Teleport (OBS / OBSpad). Pick the sender from the list; senders on the same network appear by themselves.
  3. Not listed? Type its address and port (the sender shows it) into Or an address.
  4. Its sound gets a fader in the Audio Mixer, with Filters and Audio sync offset like any other source.

Guest cameras by link (no app)

The guest needs a phone or laptop with a browserInternet on both sides
  1. Sources + › Guest Camera (link). The properties show a QR code and the Guest link.
  2. Send the link (WhatsApp, email) or let the guest scan the QR code. They allow the camera and tap Start.
  3. Their picture appears a few seconds later. New link makes a fresh one; the old one stops working.

The guest’s sound isn’t included (a web page’s sound can’t be mixed into the stream). For a remote guest with sound, ask them to stream with Larix to SRT, or use a Zoom/Teams recipe below.

Zoom, Microsoft Teams and Google Meet

Meeting apps don’t let other apps take their video directly, and Android blocks recording call sound. These recipes work today with OBSpad’s inputs:

MeetingBest way into OBSpadWhat you need
ZoomCustom live stream to a Phone / Encoder (RTMP) sourcePaid Zoom plan; “Allow live streaming › Custom live streaming service” on in Zoom settings; the host starts it from Zoom on a computer.
Microsoft TeamsNDI (clean feed per person) into an NDI Source, or RTMP-Out (“Custom Streaming” app) into a Phone / Encoder (RTMP) sourceAdmin turns on NDI or live streaming in the meeting policy; Teams on a Windows or Mac computer on the same network.

Zoom, step by step

  1. In OBSpad add a Phone / Encoder (RTMP) source and note the Server and Stream key.
  2. Zoom web settings › In Meeting (Advanced) › turn on Allow live streaming meetings › Custom Live Streaming Service.
  3. In the meeting (Zoom on a computer): More › Live on Custom Live Streaming Service. Stream URL = the Server, Stream key = the key, Live streaming page URL = any page (e.g. your church site).
  4. Spotlight the speaker so they fill the picture. Zoom sends the meeting view and its sound, a few seconds behind.

Teams with NDI, step by step

  1. The Teams admin enables NDI in the meeting policy (“Allow NDI streaming”).
  2. In Teams on the computer: Settings › App permissions › turn on NDI. In the meeting: More › Video effects / Streaming › Broadcast over NDI.
  3. In OBSpad add an NDI Source; each person appears as their own source. Pick the speaker.

For a single remote speaker, the simplest and lowest-delay option is often to skip the meeting app: send them a Guest Camera link, or ask them to stream with Larix to SRT (with sound).

Videos, pictures and slides

Files on the tablet, a USB drive, Google Drive, Dropbox or a link
  1. Media Source for videos: Browse files…, Photos / gallery…, or From a link… (Google Drive and Dropbox share links, or a direct link to a file). Files are copied into OBSpad so they keep working offline.
  2. Choose Loop, and under Audio Monitoring whether you hear it on the tablet. Play, pause and restart from the bar under the canvas.
  3. Image for pictures and lower thirds; Image Slide Show for song lyrics, announcements and photo loops with a transition and timing.

YouTube and Facebook videos can’t be downloaded in OBSpad: download your own video on the site first. Videos in H.264 MP4 play best.

Web pages and overlays

A link or a local HTML file
  1. Sources + › Browser, enter the URL (or a local HTML file), and the page size (e.g. 1920×1080 for a full-screen overlay).
  2. Use it for scoreboards, chat boxes, alerts, countdowns and lower-third widgets. Transparent pages show the scene behind them.
  3. Install overlay packs from GitHub or a .zip in Tools › Plugins; they appear under Add Source › From plugins.
Part 6

Sound

Fix sound that’s out of syncAudio sync offset

  1. Phone and network cameras often show the picture later than the mic hears it.
  2. In the Audio Mixer, tap the timer button on the mic (or video, NDI or phone source).
  3. Clap once on camera, then raise the offset until the clap sound and picture match. Up to 2 seconds.

Use a Bluetooth or wireless micHeadsets and USB receivers

  1. Wireless kits with a USB receiver (DJI Mic, Rode Wireless GO) work as USB sound cards, in full quality.
  2. Bluetooth headsets: pair them, then pick them in the mic’s input menu in the Audio Mixer.
  3. Bluetooth mics send call-quality sound with a short delay: fine for a backup, and the Audio sync offset can line them up.

Use two microphones on one USB interfaceEach input as its own mic

  1. Plug in the audio interface. OBSpad switches to it automatically.
  2. Add an Audio Input Capture source for each mic.
  3. In the Audio Mixer, set each mic to Input 1 (L) or Input 2 (R). Each gets its own fader, meter and filters.

Clean up your voiceNoise Suppression, Gate, Compressor

  1. In the Audio Mixer, tap the mic’s Mic adjustments button for one-tap noise suppression and levelling.
  2. For finer control, open the mic’s Filters and add Noise Suppression, Noise Gate, Compressor or Limiter.
  3. Watch the meter: speech should peak in the yellow, never in the red.

Play a video with its soundMedia Source and audio monitoring

  1. Add a Media Source and pick the video. Its sound goes into the stream and recording.
  2. Under Audio Monitoring, choose Stream + tablet to hear it on the tablet too.
  3. Use the play, pause and restart buttons in the bar under the canvas.

Add a video from Google Drive or DropboxFrom a link

  1. Share the file with “Anyone with the link” and copy the link.
  2. In a Media Source or Image’s properties, tap From a link… and paste it.
  3. OBSpad downloads it to the tablet, so it plays even without internet later. YouTube and Facebook links can’t be downloaded.
Part 7

Production tools

Colour-grade with a LUTApply LUT filter

  1. Select a camera or video source and tap Filters in the bar under the canvas.
  2. Add Apply LUT and browse for a .cube file (or a LUT from a plugin).
  3. Lower Amount to blend the look with the original picture.

Save an instant replayReplay buffer

  1. Set how many seconds to keep in Settings › Output › Replay buffer.
  2. Tap Start Replay Buffer in the Controls dock.
  3. After a great moment, tap Save Replay. The last seconds are saved as a file.

Add a stream delayViewers see it seconds later

  1. Open Settings › Output and set Stream delay.
  2. Start streaming: viewers see everything that many seconds late, so you have time to cut away.
  3. Recordings aren’t delayed.

Stream or record in 2K2560×1440

  1. In Settings › Video, set the Output resolution to 2560x1440 (2K) at 30 FPS.
  2. In Settings › Output, use 9000–18000 kbps and a wired or strong Wi-Fi connection.
  3. YouTube accepts 1440p; Facebook Live and Twitch scale it down, so 1080p is better there.

Send to OBS on a computer with TeleportWi-Fi, no cables, picture and sound

  1. On the computer, install the free Teleport plugin for OBS (obs-teleport) and restart OBS.
  2. In OBSpad open Tools › Plugins and turn on Teleport Output. Give it a name, for example Pulpit tablet.
  3. In OBS add a Teleport source and pick that name from its list. Your Program and its sound appear in OBS, ready to mix, record or stream from the computer.
  4. Not listed (an iPad, or a network that blocks discovery)? Type the Manual IP shown in OBSpad (like 192.168.1.20:43210) into the Teleport source’s Manual IP field.
  5. Quality 80–90 suits most Wi-Fi; lower it if the picture stutters. Frames are only made while OBS is connected, so it costs nothing when nobody watches.

Teleport needs no NDI runtime. With OBS’s Virtual Camera on, the computer can then use OBSpad as its webcam in Zoom, Meet, WhatsApp or Teams.

Send video to vMix or OBS over NDI®Same network, no cables

  1. Open Tools › Plugins and turn on NDI Output.
  2. Give it a name. It appears as an NDI source in vMix, OBS (DistroAV) or NDI Studio Monitor on the same network.
  3. The NDI runtime has to be included in the build; see ndi.video.

Install an overlay or pluginFrom GitHub or a .zip

  1. Open Tools › Plugins › Get plugins.
  2. Paste a GitHub link (owner/repo works), or tap Install from .zip…. Repos without an OBSpad manifest are converted.
  3. Web overlays then appear in Add Source › From plugins, LUTs in Apply LUT, and docks on the Plugins screen. Desktop-only OBS plugins (.dll, C/C++, Lua) can’t run on a tablet.

Work faster with a keyboardShortcuts and undo

  1. Connect a Bluetooth or USB keyboard.
  2. See every shortcut in Help › Keyboard Shortcuts: switch scenes, transition, start and stop streaming and recording.
  3. Edit › Undo and Redo (Ctrl+Z / Ctrl+Y) take back changes to scenes and sources.
Part 8

Fix common problems

Troubleshooting

ProblemTry this
Phone / Encoder says “Waiting”Both devices on the same network; the address is the tablet’s (shown in properties); the source is on Program or Preview; stream key matches exactly; the phone isn’t on mobile data.
“Set video to H.264”The phone or encoder is sending HEVC/H.265: switch its codec to H.264 (AVC). Sound must be AAC.
SRT refuses to connectTurn off the passphrase; check the Stream ID; port 9000 UDP must be reachable (router, firewall, VPN).
Picture stutters over Wi-FiLower the phone’s bitrate (3–4 Mbps), use 5 GHz Wi-Fi, switch to SRT, or use a USB-C Ethernet adapter on the tablet.
Camera error when adding a second cameraMost tablets run one camera at a time: use a phone (Phone / Encoder) for the second angle.
Capture card not foundPowered hub, another cable, replug; iPad needs iPadOS 17.
NDI source not listedSame subnet, multicast allowed on the router, tap the refresh button; check the build includes NDI.
Sound early or lateAudio sync offset in the mixer.
